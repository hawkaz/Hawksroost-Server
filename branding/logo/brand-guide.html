Brand guide · v1 · personal / family use

HawkAZ

Personal domain identity for the Hawk family in Arizona. The mark is a hawk in flight over the Arizona state silhouette; the wordmark splits the name in two tones so “AZ” reads as the place. Primary domain hawkaz.net, reserve hawkaz.cloud.

01

Logo

Two lockups. The horizontal is the default for headers, email signatures and dashboards. The square is for avatars, cards and anywhere the space is roughly 1:1. The mark alone is for icons and favicons.

02

Construction and sizing

RuleValue
Wingspan1.35× the width of the state silhouette; primaries break past both edges
Clear spaceHalf the state’s width on all sides of the lockup. Nothing enters it.
Min size — horizontal160px wide on screen, 40mm in print
Min size — square64px
Min size — icon with state32px. Below that use the hawk alone (favicon-hawk-*.svg).
Icon corner radius12.5% of tile width (64px on a 512px tile)

Do

  • Use copper state + navy hawk on light backgrounds.
  • Use copper state + cream hawk on navy or ink backgrounds.
  • Use the one-colour version for stamps, embroidery and laser work.
  • Keep the wordmark two-tone: “Hawk” in the dominant colour, “AZ” in the accent.

Don’t

  • Don’t rotate, skew, or add gradients, bevels or drop shadows.
  • Don’t recolour the hawk and state the same value — the state stops reading.
  • Don’t place the full lockup on a busy photo; use the icon tile instead.
  • Don’t retype the wordmark in another font or letterspace it.

Arizona flag palette, warmed down. Copper and navy carry the identity; gold is the accent on dark; sunset red is for emphasis only, never for the mark.

Notes for Claude Code

  • The state polygon and hawk path live inside the SVG files — inline them rather than re-drawing.
  • Dark surfaces: navy #1F3A5F or ink #2A2622 only. Gold replaces copper as the wordmark accent on dark.
  • Body copy at 400 weight, headings 800. No third typeface.
  • Personal project, not a business — no trademark, no © footer boilerplate needed.
