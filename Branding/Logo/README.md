# HawkAZ logo package

Open `brand-guide.html` in a browser — it is the handoff document (colours, sizing rules, file inventory, CSS tokens, favicon snippet).

    brand-guide.html      brand guide, self-contained
    svg/                  vector masters (scale to any size)
    png/                  raster exports; *-transparent.png have an alpha channel

Lockup: hawk in flight over the Arizona silhouette, wingspan 1.35x the state width.
Wordmark: Bitter 800, "Hawk" in navy (or cream on dark), "AZ" in copper (or gold on dark).

Below 32px use the hawk alone — `svg/favicon-hawk-navy.svg`, `png/favicon-16.png`.
